# Product Images

Product အသစ်ပုံများကို ဒီ folder ထဲ Upload တင်ပါ။

အကောင်းဆုံး filename ပုံစံ:
- `MYAT-103.jpg`
- `MYAT-104.webp`

ပြီးရင် **Actions > Add New Catalogue Product** မှာ `image_file` အကွက်ထဲ filename ကိုပဲ ရိုက်ထည့်ပါ။ Raw URL ကို ကိုယ်တိုင်ကူးစရာမလိုပါ။

အကြံပြုချက်:
- JPG / PNG / WEBP
- Square သို့မဟုတ် 4:5 product photo
- File size ကို သေးသေးထားပါ
- Filename ထဲ space မသုံးပါနှင့်
